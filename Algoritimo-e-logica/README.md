# 🧠 Algorithms and Logic

Este repositório contém meus estudos de algoritmos e lógica de programação, fundamentais para o desenvolvimento de software.

## 📚 Conteúdo

- Estruturas sequenciais
- Estruturas condicionais (if, else)
- Estruturas de repetição (for, while)
- Vetores (arrays)
- Matrizes
- Funções e métodos
- Exercícios práticos
- Simulação de escalonamento de processos (FCFS, SJF, Round Robin)
- Conversor de instruções MIPS
- Simulador de Arquitetura de Computadores

## 📁 Estrutura

```text
Algoritimo-e-logica/
 ├── 📂 Condicionais/                  # Exercícios de estruturas condicionais
 ├── 📂 Repeticao/                     # Exercícios de repetição
 │    ├── 📂 Lista1/                   # Lista de exercícios 1
 │    ├── 📂 Lista2/                   # Lista de exercícios 2
 │    └── 📂 Exercicios-fora-das-listas/
 ├── 📂 Vetores/                       # Exercícios com vetores (arrays)
 ├── 📂 Matriz/                        # Exercícios com matrizes
 ├── 📂 TESTES/                        # Arquivos de entrada e resultados dos testes
 ├── 📄 Main.java                      # Simulador de escalonamento de processos (FCFS, SJF, Round Robin)
 ├── 📄 TrabalhoArquitetura.java       # Trabalho de Arquitetura de Computadores
 └── 📄 TrabalhoMIPS.java              # Conversor de instruções Assembly MIPS
```

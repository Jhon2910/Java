# ☕ Java Studies

Este repositório contém meus estudos em Java, abordando desde conceitos básicos até programação orientada a objetos (POO).

## 📚 Conteúdo

- Fundamentos da linguagem Java
- Estruturas condicionais (if, else, switch)
- Estruturas de repetição (for, while, do-while)
- Vetores e matrizes
- Métodos e funções
- Programação Orientada a Objetos (POO)
- Estruturas de dados (Pilha, Fila, Ordenação)
- Servidor HTTP artesanal em Java
- Prática com Node.js
- Exercícios práticos
